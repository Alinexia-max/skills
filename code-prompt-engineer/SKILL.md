# 代码提示词生成指南

将技术方案/详细设计文档翻译为结构化编码prompt，使编码Agent读prompt即可直接编码，无需回读原文。

## 原则

1. **极简** — 每句话必须提供编码必需信息，可删即删
2. **去噪** — 过滤性能报告、运维手册、非本次迭代内容
3. **关键前置** — 接口/表结构/业务规则显式排列
4. **防坑** — 风险点用 `<WARNING>` 标注
5. **忠于原文** — 不添加文档中没有的功能或决策

## 压缩手法

| 手法 | 压缩前 | 压缩后 |
|------|--------|--------|
| 合并背景 | "本项目基于Spring Boot 3开发，使用Java 17……" | `Java17+SpringBoot3+Maven` |
| 表格化 | 段落描述接口/字段 | 一行一列的表格 |
| 伪代码替段落 | 大段文字描述逻辑 | 伪代码+注释 |
| 去常识 | "Controller接收请求，Service处理逻辑……" | 删除 |
| 去铺垫 | "首先……然后……最后……" | 直接列步骤 |
| 去重复 | 多处描述同一事 | 合并为一条 |

**自检**：删掉任意一句话下游能正常编码吗？能→删。

## 输入提取

**从技术方案提取**：技术栈、模块依赖、架构约束（网关/鉴权/加密）、影响编码的部署环境。

**从详细设计提取**：表结构(DDL/字段清单+主键索引约束)、接口定义(URL/方法/参数/响应+分页鉴权)、业务流程/状态机(复杂逻辑用伪代码)、文件改动清单、业务规则(计算公式/状态流转/校验逻辑)、线框图(前端专用，原文保留)。

**过滤**：跳过性能测试报告、SQL调优、运维部署、硬件配置、非本次迭代模块。背景压至1-2句。

## Prompt模板

```markdown
## 背景与技术栈
<1-3句>

## 模块说明
<上下游依赖、关联服务>

## 数据库变更
<DDL或字段清单，含类型/注释/约束>

## 接口定义
<URL、HTTP方法、请求参数、响应结构>

## 核心业务逻辑
<流程/状态机/规则，优先伪代码>

## 代码要求
<风格规范、异常处理、日志、事务、缓存>

## 文件清单
<每行一个，修改文件标注 [FILE:path:line]>

## 验收标准
<可验证标准，≥2条>

## 负面清单
<禁止做法>
```

## 风险标注

| 关键词/场景 | 标注 |
|------------|------|
| 支付/回调/重试/唯一请求号 | `<WARNING>需幂等处理</WARNING>` |
| 库存/余额/并发/锁 | `<WARNING>并发写入冲突，需加锁</WARNING>` |
| 日志表/流水表/亿级/千万级 | `<WARNING>数据量大，查询必须分页+索引</WARNING>` |
| 跨库/分布式/多数据源 | `<WARNING>多数据源，不能依赖本地事务</WARNING>` |
| 软删/is_deleted/deleted | `<WARNING>软删除表，查询需拼删除标记</WARNING>` |
| 时区/UTC/跨时区 | `<WARNING>时区敏感，存UTC展示转时区</WARNING>` |

## 场景适配

| 场景 | 策略 |
|------|------|
| 新建文件 | 完整9区块，列出所有新建文件 |
| 修改文件 | 仅变更相关上下文，标注 `[FILE:path:line]`，说明"保持原方法签名不变"等约束 |
| 追加功能 | 现有功能1-2句 + 新增点 + 集成方式 |
| 修复Bug | 现象+复现步骤+预期行为+排查线索 |

## 输出模式

- **详细模式(默认)**：完整9区块+全部标注+完整伪代码。适用：复杂任务
- **精简模式**：仅文件清单+核心逻辑+约束+风险标注。适用：简单任务/快速迭代

## 编码风格适配

| 技术栈 | 要点 |
|--------|------|
| Java+SpringBoot3 | Controller/Service/Manager/DAO四层、MyBatis-Plus DAO、`@Transactional`、Log4j2、全局异常处理 |
| Vue3+TS+AntDv4 | `<script setup lang="ts">`、axios统一封装、Pinia(Options风格)、Router4 Hash、Less |
| Uni-App | 纯JS非TS、`uni.request`封装、Uni-UI、`pages.json`路由 |

## 前端线框图处理

前端prompt**必须包含**线框图信息：
- ASCII线框图原文保留；图片格式用文字描述布局(搜索区→操作按钮→表格→分页)
- 每个区块(搜索字段+组件类型、表格列顺序、按钮位置)明确列出

页面描述结构：
```
### 页面名
**文件路径**：...
**页面布局**：
搜索区：[字段1:Select] [字段2:Input] ... [查询] [重置]
操作区：[按钮1] [按钮2]
表格列：☐|列1|列2|列3|操作
交互：[关键交互逻辑]
```
