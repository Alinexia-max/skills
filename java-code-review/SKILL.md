# Java Code Review

检测Java代码的语法错误、编码规范、性能问题。不检测JDK版本兼容性。

## 检测范围（按优先级）

1. **git staged**：执行 `git diff --cached -- '*.java'`，无staged则跳过
2. **用户选中/提供**：直接使用
3. **以上均无**：询问用户——指定文件 / 粘贴代码 / 整个项目（慎用）

## 检查维度

### 1. 语法错误（⚠️高）

| 检查项 | 说明 |
|--------|------|
| 编译错误 | 缺分号/大括号/import、方法缺返回值 |
| 空指针风险 | 潜在NPE |
| 资源泄露 | InputStream/Connection未关闭，try-with-resources未正确使用 |
| 异常处理 | 未处理/未声明throws、空catch块吞没异常 |
| 变量问题 | 未初始化/未使用 |

### 2. 编码规范（🔶中）

| 检查项 | 说明 |
|--------|------|
| 命名 | 类大驼峰、方法/变量小驼峰、常量全大写 |
| 方法过大 | 超50行应拆分 |
| 参数过多 | 超4个应封装对象 |
| 行过长 | 超120字符 |
| 魔法数字 | 未定义为常量 |
| switch缺default | 必须有default分支 |
| equals/hashCode | 必须同时覆写 |
| 缺少注释 | public API缺Javadoc |

### 3. 性能优化（⚡中）

| 检查项 | 说明 |
|--------|------|
| 循环内创建昂贵对象 | 如SimpleDateFormat |
| 字符串拼接 | 循环中用`+`而非StringBuilder |
| 集合未指定初始容量 | 已知大小时应预分配 |
| Map遍历方式 | keySet+get → 应改entrySet |
| 循环内IO/网络/DB | 应批量处理 |
| List.contains循环调用 | 应改用Set |
| 锁粒度过大 | 同步块范围应最小化 |
| 不必要的装箱拆箱 | 原始类型优先 |
