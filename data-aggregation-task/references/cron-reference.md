# Cron 表达式参考

## 格式说明

```
秒 分 时 日 月 周
```

| 字段 | 允许值 | 特殊字符 |
|------|---------|----------|
| 秒 | 0-59 | , - * / |
| 分 | 0-59 | , - * / |
| 时 | 0-23 | , - * / |
| 日 | 1-31 | , - * ? / L W |
| 月 | 1-12 或 JAN-DEC | , - * / |
| 周 | 1-7 或 SUN-SAT | , - * ? / L # |

## 常用表达式

### 每分钟

| 需求 | Cron 表达式 |
|------|-------------|
| 每分钟执行一次 | `0 * * * * ?` |
| 每5分钟执行一次 | `0 */5 * * * ?` |
| 每10分钟执行一次 | `0 */10 * * * ?` |
| 每30分钟执行一次 | `0 */30 * * * ?` |

### 每小时

| 需求 | Cron 表达式 |
|------|-------------|
| 每小时整点执行 | `0 0 * * * ?` |
| 每2小时执行一次 | `0 0 */2 * * ?` |
| 每6小时执行一次 | `0 0 */6 * * ?` |

### 每天

| 需求 | Cron 表达式 |
|------|-------------|
| 每天凌晨0点执行 | `0 0 0 * * ?` |
| 每天凌晨1点执行 | `0 0 1 * * ?` |
| 每天上午9点执行 | `0 0 9 * * ?` |
| 每天中午12点执行 | `0 0 12 * * ?` |

### 每周

| 需求 | Cron 表达式 |
|------|-------------|
| 每周日凌晨0点执行 | `0 0 0 ? * SUN` |
| 每周一上午9点执行 | `0 0 9 ? * MON` |

### 每月

| 需求 | Cron 表达式 |
|------|-------------|
| 每月1号凌晨0点执行 | `0 0 0 1 * ?` |
| 每月最后一天凌晨0点执行 | `0 0 0 L * ?` |

## 时间窗口与 Cron 对应关系

| 时间窗口 | 推荐 Cron | 说明 |
|---------|-----------|------|
| 1分钟 | `0 * * * * ?` | 每分钟执行，聚合过去1分钟数据 |
| 5分钟 | `0 */5 * * * ?` | 每5分钟执行，聚合过去5分钟数据 |
| 10分钟 | `0 */10 * * * ?` | 每10分钟执行 |
| 15分钟 | `0 */15 * * * ?` | 每15分钟执行 |
| 30分钟 | `0 0,30 * * * ?` | 每小时的0分和30分执行 |
| 1小时 | `0 0 * * * ?` | 每小时整点执行 |
| 2小时 | `0 0 */2 * * ?` | 每2小时执行 |
| 6小时 | `0 0 */6 * * ?` | 每6小时执行 |
| 12小时 | `0 0 */12 * * * ?` | 每12小时执行 |
| 1天 | `0 0 0 * * ?` | 每天凌晨0点执行 |

## 自然语言转 Cron

当用户说自然语言时，转换为 Cron 表达式：

| 用户说 | 转换为 |
|--------|---------|
| 每分钟执行一次 | `0 * * * * ?` |
| 每5分钟执行一次 | `0 */5 * * * ?` |
| 每小时执行一次 | `0 0 * * * ?` |
| 每天执行一次 | `0 0 0 * * ?` |
| 每天凌晨1点执行 | `0 0 1 * * ?` |
| 每周执行一次 | `0 0 0 ? * MON` |
| 每月执行一次 | `0 0 0 1 * ?` |

## 注意事项

1. **Spring 的 @Scheduled 不支持年字段**
   - 标准 Cron：6位（秒 分 时 日 月 周）
   - Spring：6位（同上，不支持年）

2. **? 和 * 的区别**
   - `*`：任意值
   - `?`：不指定值（用于日和周互相排斥）

3. **/ 表示增量**
   - `*/5`：每5个单位
   - `0/5`：从0开始，每5个单位

4. **L 表示最后**
   - `L`：本月最后一天
   - `6L`：本月最后一个星期五

5. **W 表示工作日**
   - `15W`：最接近15号的工作日
