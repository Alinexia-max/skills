# 寒武纪鳄鱼选股策略 - 股票分析 Skill

## 概述

⚠️ 本 skill 受口令保护。**仅当用户消息以"鳄鱼分析"开头时激活**，格式为 `鳄鱼分析 <股票名称或代码>`。其他任何形式的股票询问（如"分析一下XX"、"XX怎么样"）均不触发本 skill。

激活后，按照寒武纪选股策略的 10 因子评分体系对该股票进行深度分析，以固定格式输出分析报告，并**自动保存报告文件**。策略核心：央企/国企 + 业绩爆发 + 独一无二 + 低价低位 + 市值<200亿。

**报告保存路径（跨平台自适应）**：优先保存到**当前工作区根目录**，文件名 `{股票代码}-{股票简称}-鳄鱼分析.md`（例：`E:\研报\000928-中钢国际-鳄鱼分析.md`）。若同名的历史报告已存在，直接覆盖为最新版并在报告开头注明"第 N 次重评"及相对上一版的变化。原 Linux 路径 `/home/ubuntu/doc/{股票代码}.txt` 为历史遗留，本机不使用。

## 投资核心原则（分析时必须逐条对照）

以下 8 条是分析的基础逻辑，贯穿整个评分过程：

1. **股东背景**：央企或省国资委控股的国企（民企一票否决 — 见风控一）
2. **业绩爆发**：三年内扣非净利润增长 5-10 倍；或主要产品价格涨 2-3 倍；或单年业绩 3 倍以上增长
3. **独一无二**：产品或服务在国内不可替代，业绩不亏损
4. **主营集中**：主营业务占比集中，专注于一个领域
5. **模式简单**：业务模式简单，赚钱逻辑清晰可理解
6. **低价低位**：股价处于低位，历经三年以上盘整
7. **市值小**：总市值低于 200 亿人民币
8. **别无选择**：在行业中有独特优势，让资本没有其他选择，只能选它爆发

## 风控原则（一票否决项）

分析时必须优先检查以下 4 条一票否决项：

| 编号 | 风控条款             | 触发条件                      | 后果               |
|------|----------------------|-------------------------------|--------------------|
| 一   | 不买民企             | 实际控制人为自然人或民企      | 直接判定不买入     |
| 二   | 不买 ST 股           | 股票带有 ST 或 *ST 标识       | 直接判定不买入     |
| 三   | 不买业绩连降         | 近两年扣非净利润连续同比下降  | 直接判定不买入     |
**如果触发任一风控条款，立即输出不买入结论，无需继续评分。**

## 仓位与操作纪律（报告中必须包含）

- 账户最多同时持仓 **3 只股票**
- 主仓位不能低于总资金的 **70%**
- **原则上不使用融资**。唯一例外：千股跌停次日顺势下跌时，可使用 **30%** 融资，快速反弹后立即解除
- **中长线投资**，反对试探性交易和频繁交易
- 不在一个价位反复进出；没有把握就不买
- 不去寻找周期拐点，等周期真正走完拐点、进入上升阶段后再考虑
- 如果股价已经上涨，放弃；如果股价还没涨，进入

## 补充评估维度（可选参考，不计入 10 因子总分）

> 以下两个维度**不是 10 因子评分的一部分**，不计入 100 分总分。它们作为买入决策的**补充筛选与估值参考**，在报告末尾单独成节。当主评分临界或需交叉验证时尤其有用。

### 维度 A：五年复合增速筛选（增长底线校验）

**目的**：检验公司是否具备长期持续增长能力，而非仅靠单年爆发。

**数据来源**：`westock finance <代码> --type income --limit 6 --fields core`，取 `EndDate` 含 `-12-31` 的年报记录（T-4 至 T）：
- 营业总收入：`OperatingRevenue`
- 归母净利润：`NPParentCompanyOwners`

**严格公式**：

复合年均增长率（CAGR，指数法）：

\[
CAGR_{rev}    = \left(\frac{REV_T}{REV_{T-4}}\right)^{\frac{1}{5}} - 1
\]

\[
CAGR_{profit} = \left(\frac{PROFIT_T}{PROFIT_{T-4}}\right)^{\frac{1}{5}} - 1
\]

> 说明：从 T-4 到 T 跨越 5 个会计年度区间，故开 5 次方（指数 `1/5`）。等价写法：总增长率开 5 次方根再减 1。

五年累计增长率（校验用）：

\[
TotalGrowth = \frac{VAL_T}{VAL_{T-4}} - 1
\]

**底线校验**：

| 指标 | 底线 | 判定 |
|------|------|------|
| 营收 CAGR | ≥ 8% | ✅ / ❌ |
| 利润 CAGR | ≥ 6% | ✅ / ❌ |

**结论规则**：两项均满足 → 增长维度通过；任一不满足 → 报告中标注"不满足五年复合增速底线"，作为"放弃/观望"的强化依据（此维度为补充参考，不直接触发一票否决，但会显著削弱投资价值）。

**数据不足时**：若年报期数不足 5 个完整年度，如实标注"年报数据不足，CAGR 无法计算"，不得用季度数据外推。

### 维度 B：FCF 倍数估值

**数据来源**：`westock finance <代码> --type cashflow --limit 1 --fields all`，年报口径。

**字段与口径（务必按此对应，不得混用）**：

| 用途 | 字段 | 说明 |
|------|------|------|
| 经营现金流净额 CFO | `NetOperateCashFlow` | 单位：元 |
| 投资现金流净额 | `NetInvestCashFlow` | 单位：元，通常为负 |
| 资本开支 CAPEX | 取 `NetInvestCashFlow` 中与购建长期资产相关的部分 | 见下方注意 2 |
| 每股自由现金流（辅助） | `ShareholderFreeCFPS` / `EnterpriseFreeCFPS` | **每股口径**，不可当总额用 |
| 自由现金流（总额，辅助） | `FCFF` / `FCFE` | 已是现金流口径，**与 CFO−CAPEX 口径不同** |

**严格公式**：

\[
FCF = CFO - CAPEX
\]

\[
FCF\_Multiple = \frac{MarketCap}{FCF}
\]

其中：
- `MarketCap` = 当前总市值（统一换算为亿元口径）
- `CFO` = 年度**经营活动产生的现金流量净额**
- `CAPEX` = 年度**资本性支出** = 购建固定资产、无形资产和其他长期资产支付的现金

**简化口径（轻资产 / 工程总包企业）**：CAPEX 占比极低（年 CAPEX 通常仅 1–2 亿，相对 CFO 可忽略），此时 `FCF ≈ CFO`，故：

\[
FCF\_Multiple \approx \frac{MarketCap}{CFO}
\]

**估值判读（通用经验区间，工程 / 资源股参考）**：

| FCF 倍数 | 判读 |
|----------|------|
| < 8 倍   | 现金流估值偏便宜 |
| 8–15 倍  | 合理 |
| > 15 倍  | 偏贵 |

**注意事项**：
1. 工程总包类企业经营现金流季节性极强：Q1–Q3 通常为垫资净流出、Q4 集中回款。**必须用年报口径，不可看季度**。
2. **westock 现金流表没有独立的"购建固定资产"字段**。CAPEX 取不到精确值时，明确标注"FCF≈CFO（轻资产近似）"并给出估算区间；**不得编造 CAPEX 数值**。
3. `FCFF`/`FCFE` 与 `CFO−CAPEX` 口径不同，**不可混用**；若使用，必须在报告中注明口径来源。
4. **FCF 倍数低（便宜）与营收 / 利润下滑并存时，属于"低估值但基本面走弱"组合——便宜 ≠ 有投资价值**，需结合维度 A 综合判断。

## 分析流程

### 步骤 1：风控审查（一票否决）

并行取数：

```bash
westock quote sh600519                                          # 名称（查 ST）、总市值、股价
westock finance sh600519 --type income --limit 6 --fields core   # 扣非净利润及同比
westock profile sh600519                                        # 业务描述
westock shareholder sh600519                                    # 十大股东
```

企业性质：先用 `westock profile` + `westock shareholder` 判断控股股东；**若仍不能确定央企/省国资委属性**，才可调用 #4 公司概况取 `gsjj`（用 Node 抓取，见上文网络限制）。**仍不确定则标注"待确认"，不得靠推测认定为民企或央企。**

确认三项：
- 是否为央企/省国资委控股？（民企直接否决）
- 是否为 ST 股？（ST 直接否决）
- 近两年扣非净利润是否连续同比下降？（连降直接否决）

**通过风控审查后才进入步骤 2**，否则直接输出不买入报告。

### 步骤 2：数据收集

```bash
# 行情与市值
westock quote <代码>

# 财务（利润表 6 期 + 现金流全字段）
westock finance <代码> --type income --limit 6 --fields core
westock finance <代码> --type cashflow --limit 1 --fields all

# K 线（月线 36 期足够覆盖盘整与分位判断）
westock kline <代码> --period month --limit 36

# 简况与股东
westock profile <代码>
westock shareholder <代码>
```

期数提示：若需要 5 个完整年报，`--limit 6` 覆盖最近 6 个报告期（含年报）；不足时可加大 `--limit` 或改用 `--start/--end` 区间。

**缺口补充（仅这两项）**：用 Node 抓取 #5 营收构成、必要时 #4 公司概况，见 `references/api-endpoints.md`。

### 步骤 3：逐项评分

按照 10 因子评分体系，逐项打分：
- 完全符合 → 满分
- 部分符合 → 按比例给分
- 不符合 → 0 分
- **数据不可得 → 0 分，并在理由栏写明"数据不可得"**

**每一项评分必须附上数据支撑（注明来源命令与字段）**，不得凭空打分。

### 步骤 4：输出格式报告

总分汇总后，按照下方报告模板输出。

### 步骤 5：自动保存报告（必须执行）

分析完成后，**必须调用 `write_file`** 将完整报告内容保存到**当前工作区根目录**：

  `{workspace}/{股票代码}-{股票简称}-鳄鱼分析.md`

示例：
  - `鳄鱼分析 中钢国际` → 保存到 `{workspace}/000928-中钢国际-鳄鱼分析.md`
  - `鳄鱼分析 000831` → 保存到 `{workspace}/000831-中国稀土-鳄鱼分析.md`

> Windows 下不存在 `/home/ubuntu/doc` 目录，不要尝试写入；同名文件已存在时直接覆盖为最新版，并在报告开头注明"第 N 次重评"与相对上一版的变化。

保存时使用与终端输出完全一致的报告内容，无需额外修改。保存成功后在回复末尾提示文件路径。

## 常见误区

1. **评分时凭感觉不附数据** — 每一项评分必须有具体数据支撑并注明来源字段，不能"看起来像是"。宁可标注"数据不可得"记 0 分，也不能编造数据。

2. **忽略风控审查顺序** — 风控审查必须先于评分。民企直接否决，不要因为其他条件好就给民企打分。

3. **评分宽严不一** — 因子#1（股东背景）：民企 0 分，地市国资委 5-7 分，省国资委 8-9 分，央企 10 分。建立统一尺度。

4. **忘记操作纪律** — 报告末尾必须包含仓位纪律和融资纪律，这是策略不可分割的一部分。

5. **用 PE/PB 等估值指标替代策略因子** — 主评分严格按 10 因子，不考察 PE/PB/ROE。但可考虑「补充评估维度」（五年复合增速 + FCF 倍数，见上文）作为可选参考；该维度**不计入总分**，仅用于交叉验证，不可替代主评分因子。

6. **绕开 westock 去用 HTTP 接口** — 违反数据来源铁律。westock 有的一律用 westock，只有 **#5 营收构成** 和 **#4 公司概况** 两个缺口才允许走 HTTP 端点。

7. **联网搜索数据** — **严禁**使用 `web_search` / `WebFetch` / 浏览器检索任何行情、财务、价格、政策数据。本 skill 不使用联网搜索。

8. **`NPDeductNonRecurringPL` 可直接取扣非净利润** — 这是 westock `finance --type income` 的原生字段（单位：元），**无需再用 EPS 反推**。
   - 配套同比字段：`NPParentCompanyCutYOY`（扣非同比）、`NPPCCGrowRate3Y`（三年复合增速）。
   - 若某期该字段为空（季度报告偶发），改用归母净利润 `NPParentCompanyOwners` 并**在报告中注明口径替代**，不得编造。

9. **K 线走 westock，注意市场前缀与周期参数** — 月线 `--period month`、周线 `--period week`；同一条命令可逗号批量多股。历史遗留的东财 `klt=103/102` 月/周线写法已废弃。

10. **市值单位是「元」** — `westock quote` 的 `total_market_cap` 单位为元，除 1e8 才是亿元。实测校验：中钢国际 5.34 × 1,434,644,621 = 76.61 亿元，与返回的 7,661,000,000 一致。**不要看错量级。**

11. **非资源股策略不匹配** — 10 因子体系专为资源股设计（依赖"产品价格大涨"和"净利润爆发"）。当分析非资源股（如工程、服务、科技类企业）时，因子 #3 和 #4 可能天然得 0 分。此时在报告的"评分解读"中注明这一局限。
